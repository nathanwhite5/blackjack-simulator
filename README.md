# Blackjack Simulator

## Overview
Python-based blackjack simulator developed as a probability and simulation project using JupyterLab. The project explores blackjack gameplay logic, statistical outcomes, and simulation-based experimentation.

## Current Features
- Blackjack gameplay simulation

## Planned Features
- Dealer and player hand evaluation
- Win/loss outcome tracking
- Statistical experimentation in JupyterLab
- Strategy optimization testing
- Monte Carlo simulation expansion
- Visualization of outcome distributions
- Refactoring notebook logic into modular Python files
- Additional blackjack rule variations

## Technologies
- Python
- JupyterLab
- pandas
- random
- numpy

## Status
Work in progress.
